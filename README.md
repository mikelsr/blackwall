# Blackwall

Blackwall, or b7l, is a Rust re-implementation of [Anubis](https://anubis.techaro.lol/).

## FAQ

- **Why use WebAssembly for the challenges?**
  WASM is supported by most browsers but not as much by scrapping tools. It also let's us have a single implementation of the challenge logic for both frontend and backend.

- **Is any of the code AI generated?**
  B7L has been coded by a human (me). Many of the tests, however, have been generated by an LLM.
